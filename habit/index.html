Support

Check off a habit from the Home Screen

Touch and hold an empty area of the Home Screen. Choose Edit → Add Widget, search for Asympta Habit, choose a size and tap Add Widget. Tap the check box on the widget to finish the habit, then open Journey to see your progress. Tap the habit name to edit its record.

Set your language

Choose English or Traditional Chinese when you first open the journal. Switch later in Settings → Language.

Back up your journal

For automatic sync and backups, enable iCloud in Settings on each device using the same Apple Account and iCloud Drive. Use Settings → Export JSON backup to make a restorable copy. To load it, choose Restore JSON backup and confirm. Restoring replaces the current journal. Export a copy of your current journal first if you wish to keep it.

Capture a note

In a habit record or a goal progress entry, tap the pencil icon on an iPad to write using Apple Pencil and Scribble. Habit Plus adds an in-app microphone button that turns speech into editable text using supported on-device speech recognition. Review the note before saving the entry.

Restore or manage Habit Plus

Open Settings → Habit Plus → Restore purchases using the Apple Account you subscribed with. Manage or cancel your Apple subscription.

Contact

Email hello@everformlab.com for help. Include your app version and what happened. Remove private journal details from any attachments.

使用支援

在主畫面完成習慣

長按主畫面的空白位置，點「編輯」→「加入小工具」，搜尋 Asympta Habit，選擇尺寸並加入。點小工具的勾選框可完成習慣，再到「歷程」查看進度。點習慣名稱可編輯當日紀錄。

切換語言

首次開啟日誌時可選擇繁體中文或英文。之後可到「設定」的「語言」切換。

備份日誌

如要自動同步及備份，請在使用同一 Apple 帳號和 iCloud 雲碟的各部裝置上，於 App 設定開啟 iCloud。在「設定」點「匯出 JSON 備份」，即可建立可回復的副本。選擇「還原 JSON 備份」並確認後，備份會取代目前的日誌。若要保留目前的日誌，請先另存一份備份。

記下做過的事

在習慣紀錄或目標進度中，可於 iPad 點筆尖圖示，用 Apple Pencil 和隨手寫輸入。Habit Plus 提供 App 內的麥克風按鈕，可在支援的裝置上將語音轉為文字。儲存前可以檢查和修改。

恢復或管理 Habit Plus

使用原本訂閱的 Apple 帳號，在「設定」的 Habit Plus 頁面點「恢復購買」。也可以管理或取消 Apple 訂閱。
